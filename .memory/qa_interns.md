- `qa-interns up .` has no `--dirty` option, so commit first and run `qa-interns up . --commit <rev>`; `qa-interns validate . --dirty` and `qa-interns run . --dirty` check the working tree, and `qa-interns down` removes the environment.
- A qa-interns confirmer cancelled at its 10-minute default time box writes no `confirmation.json`, and its group stays unconfirmed in `report.md`; pass `--confirm-minutes 20` to `run` or `replay` for groups that need a build, a sign-in, or a wait on a code expiry, and judge a silent group from its adapter log and screenshots.
- A qa-interns testing intern can end `limited` before its first step while the run still ends `done` with no finding from that charter; read the intern table in `report.md`, and rerun with `--interns 3` so each `focus` entry in `.devcontainer/devcontainer.json` gets an intern, because charters are dealt in `focus` order.
- A qa-interns `report.md` and the intern `findings.json` files embed the seeded session cookie; quote findings in your own words and check each pasted line and screenshot for the cookie before posting.
- `agent-browser fill` on the `readOnly` email or code field of a pending sign-in empties the field and reports `Done`, so an emptied field during a pending request is a tool artifact; test an edit during a pending request with real key presses before calling it a defect.
- Page script cannot drive a paste into the sign-in code field, because `navigator.clipboard` answers `NotAllowedError`; use `agent-browser --session <name> clipboard write "<text>"`, focus the field, then `agent-browser --session <name> clipboard paste`.
