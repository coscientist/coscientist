- At `@tanstack/react-start` 1.168, use `.validator` (`.inputValidator` is a deprecated alias), import `getRequest`, `getRequestHeaders`, `setResponseStatus`, and `setResponseHeader` from `@tanstack/react-start/server` (`getRequest` is `undefined` on the package root), and write `loader` before `head` in a route so `loaderData` is inferred.
- `Response.redirect(...)` and `Response.error()` have immutable headers and throw `TypeError: immutable` on `headers.set` in `noStoreMiddleware`, so a redirect that passes the request middleware is built with Start's `redirect` or `new Response`; never replace a redirect object with a copy, because `isRedirect` reads its `.options` after the middleware.
- Effect 4.0.1 names differ from 3.x and the 4.0 betas: services are `Context.Service` (no `ServiceMap` module, no `Context.Tag`), `Layer.succeed(Key, value)` takes both, `Effect.tryPromise` without `catch` fails with `Cause.UnknownError`, a `Cause` exposes `reasons`, and the default logger writes to stdout until `Logger.LogToStderr` is provided; check a name in `node_modules/effect/dist/*.d.ts` before writing it from memory.
- `lib/use-intl.d.ts` types message keys only, so a call that omits an ICU argument such as `{minutes}`, `{otp}`, `{email}`, or `{length}` passes `bun run typecheck` and renders the placeholder or the key path; after changing a message or its call, read the rendered output, such as the email the dev server prints.
