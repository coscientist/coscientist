- Track node depth in `readDocument` with the recursive `visit` over `node.children` that carries `depth`; `doc.resolve(pos).depth` per node is quadratic (9 to 13 s for 50000 paragraphs against about 0.1 s for the walk), and `Fragment.forEach` fails the lint rule that reads it as `Array#forEach`. [source: https://github.com/coscientist/coscientist/pull/3]
- `readDocument` checks attribute types, not ranges: a heading `level` of 99 saves and renders as `h1`, because Tiptap falls back to the first configured level; add a `validate` to the attribute in `lib/editor/schema.ts` when a range matters. [source: https://github.com/coscientist/coscientist/pull/3]
- `generateHTML` and `generateJSON` from `@tiptap/core` throw under Node with `window is not defined`; render with `renderToReactElement` and a `nodeMapping`, and extract text with `getText` and `getTextSerializersFromSchema`.
- Never add a `markMapping.link` to the static renderer: it skips the `isAllowedUri` blanking of `href` in the link mark's `renderHTML`, and React 19 then renders a `javascript:` href.
- `schema.nodeFromJSON` drops unknown attribute keys and accepts an empty `doc`, and the static renderer builds nodes with `Node.fromJSON` and never calls `check()`, so JSON reaches the renderer only after `readDocument`.
- A custom inline node needs `group: 'inline'`, or `check()` fails with `Invalid content for node paragraph: <pageLink>`.
